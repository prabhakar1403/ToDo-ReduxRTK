About library react-toastify

It is a popular library for displaying toast notifications in React applications. Toast notifications are small messages that appear temporarily to inform users about an action or event, without blocking their interaction with the application.
toast and ToastContainer from react-toastify: Functions and components for showing toast notifications.

npm install react-toastify
import { toast, ToastContainer } from 'react-toastify';
import 'react-toastify/dist/ReactToastify.css';

use '<ToastContainer />' within the div.

'react-toastify/dist/ReactToastify.css': The CSS file for default toast styles.
